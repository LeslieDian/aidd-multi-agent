## Agent 行为观察

- Round 0 到 Round 1：Judge 建议改变尾部基团；当轮最低 Vina 从 -8.407 到 -8.565。
- Round 1 到 Round 2：Judge 建议进行核心骨架跳跃；候选采纳了该方向，但当轮最低 Vina 回落到 -8.158。
- LLM 报告的平均采纳率为 0.467，结构相似度测得的平均采纳率为 0.5。
- 单次运行无法把变化归因于 Judge 或记忆，`agent_is_learning` 因此保持 `null`。

## 试跑暴露的问题

三个已经成功评估的 SMILES 在 Round 1 被再次提出并重新 docking。当前循环只跳过批内重复和历史失败分子，
尚未缓存所有已评估结构。这造成了 3 次可以避免的重复计算，也是正式对照实验前应优先修复的问题。
