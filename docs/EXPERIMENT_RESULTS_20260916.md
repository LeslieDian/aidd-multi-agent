# AIDD Agent 对照实验结果（2026-09-16）

## 结论

本次真实实验完成 3 个实验组、每组 3 次合格重复，共 9 个运行。主指标 `best_composite_global` 上，Judge-only 和 Judge+记忆均高于基线，但证据尚不足以判定显著改善。Judge+记忆在最佳 Vina、首末轮 Vina 变化和跨轮重复数上相对基线出现显著的探索性信号；它相对 Judge-only 的直接比较仍未达到 `p < 0.05`。

因此当前可以说“工作记忆值得扩大验证”，不能说“Agent 已被证明能够自主学习”或“记忆已被证明优于 Judge-only”。

## 实验矩阵

| 组 | Judge | 工作/失败记忆 | 合格重复 |
|---|---:|---:|---:|
| `baseline` | 否 | 否 | 3 |
| `reflection` | 是 | 否 | 3 |
| `reflection_memory` | 是 | 是 | 3 |

每次运行固定为 3 轮，每轮 DeepSeek 与 MiniMax 各生成 5 个候选。三组使用同一 EGFR 受体、口袋、Vina 参数、评分代码和候选预算，并隔离记忆命名空间。完整方法见 [EXPERIMENT_MATRIX.md](EXPERIMENT_MATRIX.md)。

## 主要统计结果

数值为均值 ± 样本标准差；检验为双侧 Welch t 检验，每组 `n=3`。

| 指标 | Baseline | Judge-only | Judge+记忆 |
|---|---:|---:|---:|
| 最佳综合分 | 0.819 ± 0.014 | 0.831 ± 0.008 | 0.842 ± 0.000 |
| 最佳 Vina（越低越好） | -8.490 ± 0.097 | -8.597 ± 0.084 | -8.819 ± 0.132 |
| 首末轮 Vina 变化（越低越好） | -0.074 ± 0.068 | -0.018 ± 0.210 | -0.446 ± 0.079 |
| 跨轮重复数（越低越好） | 9.33 ± 1.53 | 5.33 ± 2.31 | 2.67 ± 0.58 |
| 唯一有效分子 | 19.00 ± 2.65 | 20.33 ± 4.62 | 22.33 ± 3.06 |
| 唯一骨架 | 13.67 ± 2.52 | 14.67 ± 5.86 | 16.00 ± 1.73 |
| hERG 启发式标记率（越低越好） | 0.771 ± 0.070 | 0.840 ± 0.049 | 0.864 ± 0.020 |
| Token | 10,144 ± 64 | 28,643 ± 1,413 | 30,376 ± 4,984 |

### 相对基线

- Judge-only 的主指标增加 `0.0123`，`p=0.266`：方向有利，证据不足。
- Judge+记忆的主指标增加 `0.0230`，`p=0.103`：方向有利，证据不足。
- Judge+记忆的最佳 Vina 改善 `-0.329`，`p=0.029`。
- Judge+记忆的首末轮 Vina 变化改善 `-0.3717`，`p=0.0037`。
- Judge+记忆的跨轮重复数减少 `6.67`，`p=0.0096`。
- Judge+记忆的 hERG 启发式标记率增加 `0.0925`，`p=0.142`：方向不利，尚不显著。

这些是小样本、未做多重比较校正的探索性结果。预先指定的主指标没有达到显著，因此不能用若干次要指标的 `p < 0.05` 宣称总体成功。

### 记忆相对 Judge-only 的增量

| 指标 | Judge+记忆减 Judge-only | Welch p |
|---|---:|---:|
| 最佳综合分 | +0.0107 | 0.133 |
| 最佳 Vina | -0.2217 | 0.081 |
| 首末轮 Vina 变化 | -0.4283 | 0.057 |
| 跨轮重复数 | -2.67 | 0.178 |
| hERG 启发式标记率 | +0.0243 | 0.494 |
| Token | +1,732 | 0.614 |

这组直接比较最能回答“记忆是否在 Judge 之外提供额外价值”。当前所有指标均未达到 `p < 0.05`，但 Vina 变化接近阈值，适合作为下一轮扩大重复数的主要验证假设。

## Agent 行为审计

- Judge-only 的平均 LLM 自报采纳率为 `0.422`，结构相似度采纳率为 `0.367`。
- Judge+记忆的平均 LLM 自报采纳率为 `0.578`，结构相似度采纳率为 `0.267`。
- Judge+记忆中，LLM 自报采纳数量相对结构判定平均高 `3.0` 个候选。

这说明 Judge 能给出具体化学修改建议，但它对“生成器是否采纳建议”的自我判断不可靠。系统应继续以分子指纹、性质变化和实际评分作为外部证据，不能用 Judge 的自然语言自评作为学习成功标签。

## 缓存与运行成本

9 个合格运行共产生 270 个原始候选，批内精确去重后评估 237 个，全部通过结构验证并完成评分。

- 缓存命中：162 次；
- 新 docking：75 次；
- 评估复用率：`162 / 237 = 68.4%`；
- 合格运行累计 Token：207,489；
- 合格运行累计用时：3,096.8 秒，约 51.6 分钟。

缓存键为 `protocol_id + canonical SMILES`，只复用相同受体、口袋、评分实现和 Vina 参数下的评分及工件。生成结果、Judge 反馈和记忆状态不进入缓存，因此不会把一个实验组的策略复制给另一个实验组。

缓存命中和运行时间受实验执行顺序影响，只作为成本指标，不用于判断哪个 Agent 策略更优。

## 质量门禁与故障处理

最终报告包含 9 个合格运行，并记录 4 个未纳入统计的尝试：2 个 Judge 失败尝试和 2 个为修复执行器而中断的尝试。

执行期间补齐了以下工程能力：

1. 每轮必须收到两个生成器各 5 个候选，否则只重试失败生成器；连续失败才淘汰该次运行。
2. Judge 请求在当前轮局部重试，避免重新生成和重新 docking。
3. JSON 解析读取第一个完整对象，并保留完整原始响应，兼容供应商追加的尾随元数据。
4. Benchmark 支持断点续跑，自动跳过已合格重复，并为中断目录补写审计状态。
5. 只有完整轮次、完整供应商预算和有效 Judge 状态的运行进入统计。

这些措施保证故障不会被误算成模型效果，也避免为一次 LLM 格式错误重复进行昂贵的物理评分。

## 为什么采用这种设计

三个实验组构成消融实验：基线测量双生成器本身，Judge-only 测量逐轮反馈的增量，Judge+记忆测量历史状态的进一步增量。若只运行完整系统，就无法判断改善来自生成器随机波动、Judge、记忆还是更多计算。

重复运行用于估计非确定性 LLM 输出带来的波动；预算匹配用于防止“生成更多候选”伪装成“策略更聪明”；记忆隔离用于防止实验组读取其他组的历史；主指标预先指定用于减少事后挑选有利指标。

## 解释边界

- 每组只有 3 次重复，95% 区间较宽，Welch 检验的稳定性有限。
- 报告同时检验多个次要指标，未做多重比较校正，显著结果应在扩大实验中复现。
- 综合分保留位数较少，记忆组三次最佳综合分均为 `0.842`，主指标对细微变化的分辨率不足。
- Vina 是固定协议下的 docking 排序信号，不是实验结合亲和力。
- 当前 ADMET 与 hERG 是 RDKit 描述符启发式，不是经过校准的毒性或药代模型。
- 记忆组的 Vina 改善伴随更高的 hERG 启发式标记率，说明优化目标仍存在“只追 docking”的偏移风险。

## 下一步判定标准

下一轮应把 `reflection` 与 `reflection_memory` 直接比较扩展到至少 10 次独立重复，继续锁定配置与主指标，并把“首末轮 Vina 变化”设为预先声明的关键次要指标。同时提高综合分内部精度、加入更可靠的 ADMET 模型和 Pareto 排序。只有当记忆相对 Judge-only 在独立重复中稳定改善，同时没有恶化安全代理指标，才进入长期自主记忆和策略更新阶段。
