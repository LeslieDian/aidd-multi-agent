# Reflection Memory 确认性实验结果（2026-09-16）

## 结论

本阶段完成了 `reflection` 与 `reflection_memory` 各 10 次、每次 3 轮的真实确认实验，共 20 个合格运行，无排除运行。

**决策：暂不批准将 `reflection_memory` 接入长期自主记忆或自动策略更新。**

记忆组通过了安全非劣效门槛，但没有改善预注册主指标，且稳定改善率只有 10%，低于 70% 的准入要求。当前记忆机制能够减少重复探索，却没有稳定提高安全可行候选的综合质量。

## 预注册门槛与结果

只有以下三项同时通过，才批准长期记忆：

1. 安全可行候选的最佳综合分显著优于 Judge-only；
2. 至少 70% 的重复运行出现迭代改善；
3. hERG 连续风险差值的 95% 置信区间上界不超过 0.05。

| 门槛 | Reflection | Reflection + memory | 组间结果 | 是否通过 |
|---|---:|---:|---:|---|
| 最佳安全综合分 | 0.795330 | 0.792653 | 差值 -0.002677；95% CI [-0.018411, 0.013057]；p=0.719937 | 否 |
| 改善运行比例 | 30% | 10% | 记忆组要求至少 70% | 否 |
| 平均 hERG 风险 | 0.640259 | 0.627626 | 差值 -0.012633；95% CI [-0.072886, 0.047619] | 是 |

安全置信区间上界 0.047619 略低于 0.05，因此本次数据支持“记忆没有造成超过预设容忍范围的安全恶化”。这不等于证明 hERG 安全，只表示相对于本实验对照没有观察到不可接受的代理风险增量。

## 关键发现

| 指标 | Reflection | Reflection + memory | 解释 |
|---|---:|---:|---|
| 最佳 Vina（越低越好） | -8.5811 | -8.4675 | 记忆组没有提高最佳 docking |
| 首轮到末轮 Vina 变化（越低越好） | +0.1055 | +0.3600 | 两组平均都回退，记忆组回退更大 |
| 安全通过率 | 33.81% | 32.72% | 基本相当，没有安全通过率收益 |
| 跨轮重复分子 | 3.3 | 0.6 | 记忆显著减少重复，差值 -2.7，p=0.001942 |
| 安全 Pareto 候选数 | 6.4 | 5.4 | 记忆没有扩大安全的非支配候选集 |
| 每次新 docking | 11.0 | 8.8 | 分层缓存和去重减少重复计算 |

记忆组在“不要再走已经失败或重复的路径”上有效，但它更像抑制器，还不是可靠的优化器。失败集合会缩小后续搜索空间；如果记忆只记录禁区而没有保留可迁移的正向结构规则，生成器容易快速收敛到较窄、但并不更优的区域。这与记忆组 Pareto 前沿候选更少、Vina 迭代回退的结果一致。

## 为什么这样设计

### 1. 每组至少 10 次，并采用交错执行

LLM 生成、候选去重和 docking 都含有波动。单次成功可能只是抽到了较好的分子。10 次重复用于估计均值、方差和 95% 置信区间；两组交错执行可以减小服务状态、缓存逐渐变热和时间漂移对某一组的偏置。

### 2. 主指标只看安全可行候选

若先选 docking 最强的分子，再单独报告安全均值，可能把高风险分子包装成进步。`best_safe_composite_global` 先要求候选通过 hERG/logP 安全门槛，再比较综合分，使“效果提升”必须发生在可接受区域内。

### 3. 综合分保留六位精度

早期三位小数会把相近候选压成并列，导致排序受输入顺序影响。六位精度减少量化碰撞，也让小幅差异能够进入统计分析；更高精度不代表模型更准确，只是避免过早丢失已有信息。

### 4. 用 Pareto 排序保留真实权衡

Vina、ADMET、hERG 和合成难度之间常有冲突。Pareto 非支配排序保留“某一目标更好且没有在其他目标上全面更差”的候选，避免单一加权总分过早删除安全更好或更易合成的路线。综合分用于同层排序，安全门槛仍拥有更高优先级。

### 5. 使用安全非劣效检验

自主优化不能为了平均效果提高而悄悄增加安全风险。非劣效检验关注风险差值置信区间的最坏合理上界；只有该上界不超过 0.05，才认为没有出现预设范围以上的安全退化。

### 6. 分层评估缓存

完整缓存以“规范化分子 + 完整评分协议”为键；docking 缓存以“规范化分子 + docking 协议”为键。相同协议再次遇到同一分子时复用 Vina 分数和工件，而 ADMET、综合分和 Pareto 排名仍按当前评分协议重算。这样既减少重复 docking，又不会在权重或安全规则改变后误用旧综合分。

本实验共记录 282 次完整评估缓存命中，并执行 198 次新 docking。每次缓存复用都保留来源元数据，便于审计评分来自哪次运行和哪套协议。

## 下一阶段建议

1. 保留失败记忆和缓存，但关闭自动长期策略写入；长期记忆继续处于只读或候选建议模式。
2. 把记忆拆成“负向约束、正向结构变换、适用上下文、证据强度”四类，避免只有失败黑名单。
3. 让策略更新基于多次运行的结构变换收益，而不是单个候选或单轮 Judge 文本；对每条规则维护成功率和安全影响。
4. 在下一轮实验中加入记忆检索消融：无记忆、失败记忆、正负记忆、置信度加权记忆，继续以 Judge-only 为基线。
5. 在进入企业级自主更新前，用真实或经校准的 hERG/ADMET 预测器替换当前启发式代理，并增加外部验证集。Vina 和当前 hERG 分数只能支持工程筛选，不能作为实验药效或临床安全结论。
