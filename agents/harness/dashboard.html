Harness 在这个项目中做什么？

这里的 harness 是模型周围的执行控制层。模型提出下一步动作，它负责检查参数和预算、调用工具、保存结果，并处理重试、暂停和恢复。

你的目标 → 模型选择动作 → Harness 执行工具 → 保存证据 → 决定下一步

本控制台连接项目自建的 agents/harness/。原来的 loop.py 保留固定工作流；新的 agent_task.py 和本控制台使用这套执行控制层。它提供可靠运行条件，化学判断和结果质量仍取决于模型与评估工具。
